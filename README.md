# bspinn

Coil sensitivity map (CSM) estimation for parallel MRI in which each receive coil is modelled as
**differentiable Biot–Savart current loops** plus a **physics-informed neural network (PINN)** correction.
Works on Cartesian 2D slices, 3D volumes, dynamic (cine) series and non-Cartesian (radial, spiral) data,
for any number of coils.

> [!WARNING]
> **Experimental research code.** This method, its implementation, the evaluation scripts and most of the
> documentation were generated by an AI coding agent as a case study of AI-driven methods development,
> supervised by one MR physicist. The results on the benchmark data are comparable to NLINV, but the
> mathematical and physical description has **not been independently verified**: in particular the
> receive-field convention, the treatment of B0, and how much of the final maps comes from the Biot–Savart
> model versus its non-physical corrections (smooth per-coil factor, IRGN refinement). Use it to experiment,
> not as a validated tool.

## Installation

Requires Python ≥ 3.10. GPU (CUDA) strongly recommended; the CPU works but is slow (minutes per slice).

With [uv](https://docs.astral.sh/uv/), from a clone (recommended for running the scripts and tests):

```bash
git clone https://github.com/maartenterpstra/bspinn.git
cd bspinn
uv sync --extra all          # creates .venv with bspinn + all optional dependencies
uv run pytest                # optional: the test suite (slow on CPU)
```

Or install it into an existing environment / project:

```bash
uv pip install "bspinn[all] @ git+https://github.com/maartenterpstra/bspinn.git"
# in a uv project:
uv add "bspinn[all] @ git+https://github.com/maartenterpstra/bspinn.git"
```

PyTorch: on Linux the default PyPI wheel includes CUDA. For a specific CUDA version, or to let uv detect
it, install with `uv pip install --torch-backend=auto ...`.

Optional extras: `fastmri` (h5py), `ocmr` (ISMRMRD), `noncart` (MRI-NUFFT, finufft), `eval` (scikit-image,
pillow), `all`, `dev` (all + pytest). The comparison methods ESPIRiT and NLINV in the evaluation scripts
need [BART](https://mrirecon.github.io/bart/); set `BART=/path/to/bart` (the scripts also look for `bart/bart`).

## Usage

### 2D slice (Cartesian)

```python
import numpy as np
from bspinn.api import estimate_maps, sense_image

# ksp: (coils, x, y) complex k-space, zero where not acquired; mask: (x, y) bool
maps, image, info = estimate_maps(
    ksp, "2d",
    mask=mask,
    calib=24,                # size of the fully sampled centre
    spacing=(dx, dy),        # mm
    plane="coronal",         # B0 orientation if known: 'axial', 'coronal', 'coronal_t', or a B0 vector
    noise=noise,             # optional (n_samples, coils) noise scan for prewhitening
    solve_image=True,        # maps and image estimated jointly (the benchmarked setting)
    device="cuda",
)
# maps: (coils, x, y), RSS-normalised; image: (x, y), TGV + low-resolution phase constraint
```

Defaults (v59): IRGN refinement of the maps (`refine="auto"`), TGV image prior with a phase constraint that
cross-validation switches on or off per slice (`image_prior="auto"`), fold-over check (`fold="auto"`).
`refine=None` / `image_prior=None` switch them off. For fully sampled test data,
`undersample=4` (or `undersample=dict(R=4, pattern="vd", seed=1)`) undersamples retrospectively.
With `plane="auto"` the B0 orientation is searched; for oblique slices pass the B0 direction in image
coordinates (row, column, normal), e.g. from the raw-data header.

Reconstruct with given maps:

```python
img = sense_image(ksp, maps, "2d", mask=mask, prior="auto", device="cuda")   # prior=None: Tikhonov CG-SENSE
```

### Cardiac cine

```python
from bspinn.ocmr import cine_slices
from bspinn.prior import dynamic_prior_image

for s, k, info in cine_slices("fs_0021_3T.h5", "mid"):      # k: (coils, x, y, frames)
    ...                                                       # undersample to ku with mask m (x, y, frames)
    cnt = m.sum(-1)
    kavg = ku.sum(-1) / np.maximum(cnt, 1)[None]
    maps, _ = estimate_maps(kavg, "2d", mask=cnt > 0, plane=info["b0_dir"], readout_axis=0,
                            spacing=info["pixel_spacing_mm"], device="cuda")
    maps = maps / np.sqrt((abs(maps) ** 2).sum(0, keepdims=True))
    image = dynamic_prior_image(ku, maps, m, "auto", spatial_on="difference", device="cuda")
```

Per-frame maps with a low-rank model of coil motion: `estimate_maps(ku, "dynamic", mask=m, rank=2, ...)`
(by default the per-frame corrections are kept only if they predict withheld lines better;
`dynamic_validate=False` keeps them).

### Non-Cartesian

```python
from bspinn.noncart import estimate_maps_noncart, sense_image_noncart

maps, info = estimate_maps_noncart(y, traj, (n, n), spacing=(dx, dy), plane="axial", calib=24, device="cuda")
image = sense_image_noncart(y, maps, traj, (n, n), prior="tv", device="cuda")
```

### 3D

`estimate_maps(ksp, "3d", spacing=(dx, dy, dz), axes="auto")` for (coils, x, y, z) data;
`physics="helmholtz"` uses a wave-aware (full-wave) correction. 3D and Helmholtz are implemented but have
not been evaluated as thoroughly as 2D.

### Command line

```bash
bspinn fit ksp.cfl --out runs/mydata --plane axial --pixel-spacing 1 1   # BART .cfl, fastMRI .h5, .npy/.npz
bspinn synthetic --coils 12 --out runs/synth                              # synthetic data with ground truth
```

## Evaluation scripts

`scripts/` contains the benchmark and figure scripts used for the ISMRM 2027 abstracts, e.g.

| Script | Purpose |
|---|---|
| `run_v59.sh` | full benchmark: static slices, image priors, OCMR cines, prospective cines, phase-pole planes |
| `evaluate_methods.py` | maps and reference-free metrics on static slices (ESPIRiT, NLINV, proposed, ...) |
| `prior_eval.py` | image reconstruction with Tikhonov / TV / TGV for each map set |
| `ocmr_eval.py`, `ocmr_prospective.py` | cardiac cines, retrospective and prospective |
| `phase_pole_eval.py` | phase singularities on small calibration regions |
| `ocmr_maps.py`, `show_cine.py`, `cine_gif.py` | per-method maps and reconstructions of a cine; animated comparisons |
| `ismrm_figures.py`, `dashboard_bundle.py` | figures and a results dashboard |

Dataset paths are arguments (`--base-folder`, `--files`); no data is included in this repository.

## Status and limitations

- Benchmarked on 20 static fastMRI/Calgary-Campinas slices and 9 + 3 OCMR cines: image quality equivalent to
  NLINV, better than ESPIRiT. The same data were used during development; there is no held-out test set yet.
- No ablation yet of the physical model against its non-physical corrections.
- About 15 s per 2D slice on a GPU (NLINV: about 1 s).
- Results vary slightly with the random seed (`seed=`).
